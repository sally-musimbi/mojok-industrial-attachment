# Assignment 003: PHP & MySQL Dynamic Website and Admin Dashboard

## Project Overview
This project extends Assignment 002 by converting the fictional corporate website into a database-driven application using PHP and MySQL.

## Objectives
- Display services and portfolio projects dynamically from a database.
- Create a secure administrator login and logout system.
- Implement CRUD operations for services and projects.
- Save and manage contact enquiries.
- Apply server-side validation and security measures.

## Technologies
- PHP 8.x
- MySQL or MariaDB
- HTML5
- CSS3
- JavaScript
- Apache

## Planned Database Tables
- `admin_users`
- `services`
- `projects`
- `enquiries`

## Security
- PDO prepared statements
- Password hashing and verification
- PHP sessions
- CSRF tokens
- Server-side input validation
- HTML output escaping

## Setup Instructions
1. Install PHP 8.x, a web server, and MySQL or MariaDB.
2. Create the project database.
3. Import `schema.sql` into the database.
4. Configure the local database credentials.
5. Start the web server and database service.
6. Open the project through the local development server.

## Testing
Testing will cover authentication, input validation, database operations, access control, and security.
