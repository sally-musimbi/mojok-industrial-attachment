ICT FUNDAMENTALS RESEARCH
1. HTML
HTML stands for Hypertext Markup Language. It is the standard language used to structure content on webpages.
It is used to create the structure of webpages, including headings, paragraphs, images, forms and links.
Practical example:
A company can use HTML to create the structure of its website's home page.
2. CSS
CSS stands for Cascading Style Sheets. It is a language used to control the appearance and layout of webpages.
It is used to add styles such as colours, fonts, spacing, borders and page layouts.
Practical example:
A developer can use CSS to change the background colour, font size and layout of a company's website.
3. JavaScript
JavaScript is a programming language commonly used to make websites interactive and dynamic.
It can be used to respond to user actions, validate forms, update webpage content and create interactive features.
Practical example:
JavaScript can check whether a user has entered a valid email address before submitting a registration form.
4.PHP
PHP is a server-side programming language commonly used for web development.
It is used to create dynamic websites and process information submitted through web forms.
Practical example:
A PHP application can process a customer's login details and retrieve their information from a database.
5. Python
Python is a high-level programming language known for its relatively simple and readable syntax. It is used for web development, data analysis, automation, artificial intelligence and other software development tasks.
Practical example:
Python can be used to develop an inventory management system for a phone repair shop.
6. Django
Django is a web framework written in Python. It provides tools for building web applications.
It helps developers create secure and structured web applications more efficiently.
Practical example:
Django can be used to build a customer and repair management system for a phone repair business.

7. FastAPI
FastAPI is a Python framework designed for building APIs and web applications.
It is commonly used to create APIs that allow different software systems to communicate with each other.
Practical example:
A company can use FastAPI to create an API that allows a mobile application to retrieve customer information from a server.
8. MySQL
MySQL is a relational database management system that uses SQL to manage data.
It is used to store, organize and retrieve structured information.
Practical example:
A phone repair system can use MySQL to store customer, device and repair records.
9. PostgreSQL
PostgreSQL is an open-source relational database management system.
It is used to store and manage structured data for applications and business systems.
Practical example:
A school management system can use PostgreSQL to store student, teacher and examination information.
10. Apache
Apache is a web server software used to deliver websites and web applications to users over the internet.
It receives requests from users' browsers and provides the requested web content.
Practical example:
Apache can be used to serve a company's website to visitors through the internet.
11. Nginx
Nginx is web server and reverse-proxy software commonly used to handle web traffic. It can serve websites, handle incoming requests and work as a reverse proxy in front of application servers.
Practical example:
Nginx can receive requests for an online business website and forward application requests to a backend server.
12. Linux
Linux is an open-source operating system used on computers, servers and other devices.
It is widely used for running servers, applications and development environments.
Practical example:
A software development company can use a Linux server to host a web application.
13. Git
Git is a distributed version control system used to track changes in files and source code. It allows developers to save versions of their work, work on different branches and collaborate with other developers.
Practical example:
A developer can use Git to keep track of changes made to a Django project.
14. GitHub
GitHub is a platform for hosting and collaborating on Git repositories.
It allows developers to store code online, collaborate on projects and manage software development work.
Practical example:
An attachment student can upload their industrial attachment projects to a GitHub repository so that their supervisor can review them.
15. REST API
REST API is an approach for building web APIs that allow different software applications to communicate using HTTP. It is used to allow applications to request, send, update and manage data through web-based endpoints.
Practical example:
A mobile application can use a REST API to request a customer's repair status from a phone repair system.
16. DNS
DNS stands for Domain Name System. It translates domain names into IP addresses that computers can use to locate servers. It allows people to access websites using easy-to-remember domain names instead of numerical IP addresses.
Practical example:
When a user enters a company's domain name in a browser, DNS helps direct the browser to the server hosting that website.
17. SSL/TLS
SSL/TLS refers to security protocols used to encrypt communication between a user's device and a server. Modern websites generally use TLS. It helps protect information such as passwords and payment details while they are being transmitted over a network.
Practical example:
An online banking website can use HTTPS with TLS to protect information exchanged between customers and the bank's server.
18. Cloud Computing
Cloud computing is the delivery of computing resources such as storage, servers, databases and software through the internet. It allows organizations to use computing resources without necessarily maintaining all the physical infrastructure themselves.
Practical example:
A business can store application data and host its website on a cloud platform instead of running its own physical server.
