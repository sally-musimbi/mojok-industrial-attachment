# Nexora Digital Solutions - Responsive Business Website

## Project Description

Nexora Digital Solutions is a fictional Kenyan technology company website developed as part of Assignment 002. The website presents the company's services, projects, background, and contact information through a responsive multi-page design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Website Pages

- Home
- About Us
- Services
- Portfolio
- Contact

## Key Features

- Responsive design for desktop, tablet, and mobile devices
- Responsive navigation menu
- Hover effects and call-to-action buttons
- Contact form with client-side validation
- Back-to-top button
- Dynamic copyright year
- Consistent navigation and footer across pages
- CSS Grid and Flexbox layouts
- Semantic HTML structure

## How to Run the Project

1. Download or clone the repository.
2. Open the `assignment-002` folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to access the other pages.

## Contact Form

The contact form performs client-side validation using JavaScript. No backend or database is connected to the form.

## Limitations

- The contact form does not send messages to a server.
- The portfolio projects are fictional examples created for the assignment.
- No backend database has been implemented.
